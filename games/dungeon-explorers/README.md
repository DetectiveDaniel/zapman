# DUNGEON EXPLORERS

A self-contained pixel-art browser game. Collect coins in the dungeon, survive Wave One, then battle missile-firing cars in Level Two.

## Play

Open `index.html` in a browser.

## Controls

- Move: WASD or arrow keys
- Swing sword: F
- Pause: Space
- Restart: R

## Stages

- Wave One: collect 8 coins while raiders chase you.
- Level Two: cars fire missiles, and each missile takes two sword slashes to destroy.
