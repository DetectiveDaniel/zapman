# Super Shuriken

A self-contained 2D browser action game. Defend a bright meadow as a ninja, throw spinning shurikens at incoming robots, and dodge increasingly frequent laser fire.

Open `index.html` directly in a modern browser. No installation or server is required.

## Controls

- **A / D** or **Left / Right**: move
- **W / Up**: jump
- **Mouse**: aim
- **Click**: throw toward the pointer
- **Space**: throw forward
- **P / Escape**: pause
- Touch controls appear automatically on smaller/touch screens.
