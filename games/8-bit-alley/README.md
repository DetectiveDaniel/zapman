# Imaginecraft

A tiny pixel-styled game picker for six fictional games. Open `index.html` in a browser, browse the arcade shelf, and press **Pick a Game** to get a random idea.

Press **Play** to show the imagination prompt and start that world's original looping music. The six soundtracks range from gentle garden melodies to fast space racing and neon dance beats. Use **Music: On/Off** to mute or resume. Choosing another game stops the previous soundtrack, and music pauses when the tab is hidden. Audio uses the browser's Web Audio API and needs no external files or services.

## Games

- Starforge Drift
- Meadowbound
- Circuitfall
- Emberfall Arena
- Skyloom Tales
- Neon Tides
