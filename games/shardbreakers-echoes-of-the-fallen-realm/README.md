# Shardbreakers: Echoes of the Fallen Realm

A browser action RPG prototype set across the shattered floating islands of Aetherion.

## Play

Open `index.html` in a browser.

## Controls

- `WASD` or arrow keys: move
- Mouse: aim
- Mouse click: strike
- `Space`: jump
- `Shift`: dash, including in the air
- `E`: Echo pulse
- `1` / `2` / `3` / `4`: attune Fire, Storm, Void, or Life
- `F5`: toggle first-person rift sight

## Goal

Seal every rift before realm integrity reaches zero. Defeat timeline beasts to gather Echo energy, use shard powers to survive anomaly events, and keep moving between the sky islands.
