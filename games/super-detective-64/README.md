# Super Detective 64

A browser canvas mansion game starring Detective Daniel, Ninja Matisse, Pirate WJ, Rose, and Henry.

Open `index.html` in a browser to play.

## Controls

- WASD or arrow keys: move
- Mouse: look around in first person after clicking or hovering over the game
- Space: jump
- F: kick
- G: character power
- C: switch camera
- 1-5: switch character
- R: restart the level
- Skip Level button: jump to the next level

Clear the Jim Slattery agents in each mansion level, then reach the gold exit rug.
Pirate WJ's pistol takes 4 seconds to recharge; the other hero powers recharge in 1 second.
